
3. `setup.ps1` 不是幂等安装器：检测到 `team` 表即停止，避免覆盖已有数据。

## 3. 初始化（二选一）

### 3.1 方式一：使用 setup.ps1（推荐）

以 PowerShell 在项目根目录运行：

```powershell
cd "D:\互联网开发2026\大作业\Internet-Database-Development\data\team\advanced"
powershell -ExecutionPolicy Bypass -File .\setup.ps1 `
  -PhpPath "D:\xampp\php\php.exe" `
  -MysqlPath "D:\xampp\mysql\bin\mysql.exe" `
  -DbHost 127.0.0.1 -DbPort 3507 -DbName worldcup `
  -DbUser root -DbPassword ""
```

参数说明：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| `-PhpPath` | `D:\xampp\php\php.exe` | PHP CLI 路径 |
| `-MysqlPath` | `D:\xampp\mysql\bin\mysql.exe` | mysql 客户端路径 |
| `-DbHost` | `127.0.0.1` | 数据库主机 |
| `-DbPort` | `3306` | 数据库端口；本机 3306 被占用时改为实际端口（本次为 3507） |
| `-DbName` | `worldcup` | 数据库名 |
| `-DbUser` | `root` | 数据库用户 |
| `-DbPassword` | 空 | 数据库密码 |

脚本依次完成：

1. 校验 PHP、mysql 客户端和 `data/install.sql` 是否存在；
2. 缺少 `common/config/main-local.php` 时执行 `php init --env=Development --overwrite=All`；
3. 用参数改写 `main-local.php` 中的 `dsn`、`username`、`password`；
4. 数据库不存在则创建（`utf8mb4` / `utf8mb4_unicode_ci`）；
5. 检测 `team` 表，已存在则停止并提示，不覆盖数据；
6. 执行 `php yii migrate --interactive=0` 创建 `user` 表；
7. 导入 `data/install.sql`（11 张业务表 + 样本数据）。

完成后按脚本提示继续第 5 节创建管理员并启动服务。

### 3.2 方式二：手动执行

```powershell
cd "D:\互联网开发2026\大作业\Internet-Database-Development\data\team\advanced"

# 1) 安装依赖
composer install

# 2) 生成本地配置（首次）
D:\xampp\php\php.exe init --env=Development --overwrite=All

# 3) 编辑 common/config/main-local.php，确认 db 配置：
#    'dsn' => 'mysql:host=127.0.0.1;port=3507;dbname=worldcup'
#    'username' => 'root'
#    'password' => ''
#    'charset' => 'utf8mb4'

# 4) 创建数据库
D:\xampp\mysql\bin\mysql.exe -h 127.0.0.1 -P 3507 -u root `
  -e "CREATE DATABASE IF NOT EXISTS worldcup DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 5) 创建 user 表
D:\xampp\php\php.exe -d extension=intl yii migrate --interactive=0

# 6) 导入业务表与样本数据
D:\xampp\mysql\bin\mysql.exe -h 127.0.0.1 -P 3507 -u root `
  --default-character-set=utf8mb4 worldcup `
  -e "source D:/互联网开发2026/大作业/Internet-Database-Development/data/install.sql"
```

注意：

- 导入命令必须带 `--default-character-set=utf8mb4`，否则中文可能乱码或触发排序规则错误。
- `source` 路径使用正斜杠 `/`，避免反斜杠转义。
- `install.sql` 不能在已有业务表的库上重复执行。

## 4. 目录权限与运行目录

首次运行前创建会话与临时目录（Windows 下通常无需额外授权，但目录必须存在）：

```powershell
New-Item -ItemType Directory -Force -Path frontend\runtime\sessions, backend\runtime\sessions | Out-Null
New-Item -ItemType Directory -Force -Path frontend\runtime, backend\runtime, frontend\web\assets, backend\web\assets | Out-Null
```

`frontend/runtime`、`backend/runtime`、`frontend/web/assets`、`backend/web/assets` 必须可写，否则会出现 500 或资源 404。

## 5. 创建管理员账号

```powershell
D:\xampp\php\php.exe -d extension=intl yii admin/init
```

交互流程：

1. 显示将创建的用户名（来自 `backend/config/params.php` 的 `adminUsername`，默认 `admin`）；
2. 输入管理员邮箱（格式校验、不得重复）；
3. 两次输入初始密码（8—64 个字符，隐藏输入）；
4. 输入 `y` 确认创建。

约束：

- 必须在本机 Windows 的**交互终端**运行，非交互环境会拒绝执行；
- 已存在同名账号时直接拒绝，不覆盖密码；
- 密码不写入命令行参数、日志或文档；
- 首次登录后台后请立即修改密码。

## 6. 启动服务

### 6.1 PHP 内置服务器（推荐用于验收）

前台：

```powershell
D:\xampp\php\php.exe -d extension=intl `
  -d session.save_path=frontend\runtime\sessions `
  -d sys_temp_dir=frontend\runtime `
  -S 127.0.0.1:8080 -t frontend\web
```

后台（另开一个 PowerShell 窗口）：

```powershell
D:\xampp\php\php.exe -d extension=intl `
  -d session.save_path=backend\runtime\sessions `
  -d sys_temp_dir=backend\runtime `
  -S 127.0.0.1:8081 -t backend\web
```

`-d session.save_path` 与 `-d sys_temp_dir` 用于避免默认临时目录不可写导致的 500。若 PHP 已启用 `intl`，可去掉 `-d extension=intl`。

### 6.2 Apache（可选）

将 `frontend/web` 与 `backend/web` 分别配置为两个虚拟主机的 DocumentRoot，并确保 `AllowOverride All`、`mod_rewrite` 可用。项目默认未启用 URL 美化，使用 `index.php?r=...` 即可访问。

## 8. 重复执行与数据还原

### 8.1 重复执行保护

- `setup.ps1` 在导入前检查 `team` 表；存在即停止，不会重复建表或覆盖样本。
- `install.sql` 本身不是幂等脚本，禁止手工重复执行。
- `php yii migrate` 可重复执行，已应用的迁移会被跳过。
- `php yii admin/init` 检测到同名账号会拒绝创建，不会重置密码。

### 8.2 完全重置

确认无需保留数据后：

```powershell
D:\xampp\mysql\bin\mysql.exe -h 127.0.0.1 -P 3507 -u root `
  -e "DROP DATABASE IF EXISTS worldcup;"
```

然后重新执行第 3 节初始化与第 5 节管理员创建。

### 8.3 备份

```powershell
D:\xampp\mysql\bin\mysqldump.exe -h 127.0.0.1 -P 3507 -u root `
  --default-character-set=utf8mb4 --databases worldcup > worldcup-backup.sql
```

## 9. 常见问题

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 页面 500，日志提示 session 目录不可写 | 默认临时目录（如 `D:\xampp\tmp`）不可写 | 按第 6 节加 `-d session.save_path` 与 `-d sys_temp_dir`，并确保目录存在 |
| `could not find driver` | 未启用 `pdo_mysql` | 在 `php.ini` 启用 `extension=pdo_mysql` |
| 提示缺少 `intl` | CLI 未加载 intl | 启动与命令前加 `-d extension=intl`，或在 `php.ini` 启用 |
| 3306 端口无法启动数据库 | 端口被其他 MySQL 占用或被 Windows 保留 | 使用现有实例的实际端口，并在 `main-local.php` 与 `setup.ps1 -DbPort` 中保持一致 |
| 导入时报 `Illegal mix of collations` | 客户端字符集不是 utf8mb4 | 导入命令加 `--default-character-set=utf8mb4` |
| `composer install` 报 CA/SSL 错误 | 本机 CA 配置缺失 | 设置 `COMPOSER_CAFILE` 指向可用的 `curl-ca-bundle.crt` 后重试 |
| `admin/init` 提示“请在 Windows 本机交互终端运行” | 在非交互脚本或非 Windows 环境执行 | 打开 PowerShell 窗口手动运行 |
| 后台登录 400 | 表单缺少 CSRF 或字段名错误 | 使用浏览器页面登录；自动化测试需带 `_csrf-backend` 与 `AdminLoginForm[...]` 字段 |
| 统计接口 500 | 数据库连接异常或表结构缺失 | 检查 `main-local.php`，确认已执行 migrate 与导入 install.sql |
| 对比页切换后数据不更新 | 浏览器禁用 JavaScript 或请求失败 | 开启 JavaScript；失败时点击卡片内“重试” |

## 10. 统计口径与实现位置

- 统计服务：`common/services/TeamStatsService.php` 的 `getSummary($teamId, $year = 2026)`。
- 仅统计 `status = finished` 且双方比分非 NULL 的比赛；每场比赛只计一次。
- 比分含加时、不含点球大战；点球决胜按平局计。
- 返回固定 8 个整数字段：`team_id`、`tournament_year`、`played`、`wins`、`draws`、`losses`、`goals_for`、`goals_against`，且 `played = wins + draws + losses`。
- 错误约定：参数非法 400，球队不存在 404，服务异常 500 且不泄露 SQL/堆栈。

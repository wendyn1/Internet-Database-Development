## 3. 关键实现说明

### 3.1 比赛状态与比分

- 状态为 `finished` 时，双方比分必须同时为非负整数；其他状态双方比分必须为 `NULL`，避免“未结束却有比分”的脏数据。
- 比分含加时、不含点球大战；点球决胜按平局计入统计。
- 库外对手通过 `home_team_id`/`away_team_id` 为 `NULL`、同时保留展示名称实现；至少一侧必须关联本库球队，两侧不能相同。

### 3.2 统计存在时的字段锁定

`FootballMatch::LOCKED_ATTRIBUTES` 包含赛事年份、双方球队 ID 与名称、状态、双方比分。模型在保存前查询该场是否存在球员统计，存在则比较原值与新值，任何锁定字段变化都会产生校验错误。后台表单同时将这些控件置灰，形成“界面提示 + 服务端强制”的双重约束。解锁只能通过删除该场全部统计完成，不能通过自动删除统计实现。

### 3.3 球员统计校验

- 只能关联 `finished` 比赛；
- 阵容记录的 `tournament_year` 必须等于比赛年份；
- 阵容所属球队必须是本场主队或客队；
- 进球数不得超过本队本场比分；
- `appeared = 0` 时进球必须为 0，已知助攻也必须为 0；
- 助攻为 `NULL` 表示“未核实”，前台显示“未核实”，不按 0 处理；
- `match_id + team_player_id` 唯一，防止同场重复统计。

### 3.4 统计服务

`TeamStatsService::getSummary($teamId, $year = 2026)` 使用一条聚合 SQL：

- 只取 `status = 'finished'` 且双方比分非 `NULL` 的比赛；
- 每场比赛对指定球队只计一次，不 JOIN 球员统计表，避免一场重复计数；
- 胜平负按本队进球与失球比较；
- 返回并强制转换为整数的 8 个字段；
- 参数非法抛 `InvalidArgumentException`（400），球队不存在抛 `DomainException`（404），其他异常由控制器转为 500 且不泄露 SQL。

### 3.5 图表与 AJAX

- 饼图使用浏览器原生 Canvas 绘制，不引入第三方图表库。
- 初始渲染读取卡片 `data-*` 属性；切换下拉框时以 GET 请求 `/team/stats` 获取 JSON，仅更新对应卡片、饼图和标题。
- 使用 `AbortController` 与请求令牌：快速连续切换时，过期响应不会覆盖最新选择。
- 零场比赛显示空状态而不绘制空饼图；请求失败显示错误提示与“重试”按钮。

### 3.6 留言接入（C8）

- 比赛详情不再自行保存留言，改为挂载组长的 `frontend\widgets\CommentWidget`，表单提交到统一的 `/comment/create`。
- 在 `frontend/config/params.php` 中为 `match` 配置详情路由 `/football-match/view` 与存在性检查；球队、球员目标由 B 配置。
- 待审核留言不在前台公开；提交成功 303 返回详情并提示审核后显示。

## 4. 验证证据

### 4.1 统计接口

| 请求 | 结果 |
| --- | --- |
| `/team/stats?team_id=3` | 200，`played=3, wins=3, draws=0, losses=0, goals_for=4, goals_against=0` |
| `/team/stats?team_id=abc` | 400 |
| `/team/stats?team_id=999` | 404 |

六个样本球队的返回值均与手工按比赛逐场计算一致，且满足 `played = wins + draws + losses`。

### 4.2 业务规则脚本

以下场景均通过脚本或后台表单实测，事务回滚后未污染样本数据：

- 已结束比赛缺少比分：拒绝；
- 未结束比赛填写比分：拒绝；
- 双方为同一球队、两侧均为库外：拒绝；
- 存在统计后修改比分/球队/状态/年份：拒绝；
- 非已结束比赛录入统计：拒绝；
- 进球超过本队比分：拒绝；
- 阵容年份或球队与比赛不匹配：拒绝；
- 未出场但进球不为 0：拒绝；
- 同场重复统计：拒绝；
- 官方编号为空的多场比赛共存：允许。

### 4.3 页面与交互

- 比赛列表 8 行，筛选、分页正常；库外对手不生成球队链接；
- 比赛详情（ID 104）显示比分、球员统计与留言表单；
- 对比页两个饼图正常渲染，无控制台错误；
- AJAX 切换球队后对应卡片场次、胜场与标题更新，URL 不变；
- 后台登录后场馆、比赛、球员统计列表均可访问；
- 场馆被比赛引用时删除被拒绝；比赛存在统计时表单字段锁定；
- 留言提交返回 303，数据库写入 `pending`，前台公开区不显示，非法比赛 ID 返回 404。
